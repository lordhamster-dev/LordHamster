## 🌟 简介

Yazi 是一款超好用的终端文件管理器，让你的命令行操作效率起飞！✨

## 💡 主要功能

- 快速文件浏览
- 批量操作
- 快捷键支持
- 自定义配置

## 🛠️ 安装方法

```bash
# 使用cargo安装
cargo install yazi
```

## 🔑 常用快捷键

- `j/k`：上下移动
- `h/l`：进入/返回目录
- `Space`：选择文件
- `y`：复制路径
- `p`：粘贴

## ⚙️ 自定义配置

配置文件路径：`~/.config/yazi/`

## 🎯 使用场景

- 快速整理文件
- 批量重命名
- 高效文件操作
